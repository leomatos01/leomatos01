📋 Requisitos Funcionais (RF)

IDDescriçãoStatus
RF01O usuário deve se identificar (nome) e escolher um perfil (aluno ou professor) para acessar a aplicação.✅ Implementado
RF02O sistema deve persistir o progresso do usuário entre sessões, no próprio navegador.✅ Implementado
RF03O conteúdo deve ser organizado em uma trilha de módulos sequenciais, liberando o próximo apenas com nota mínima no anterior (RN01).✅ Implementado
RF04O sistema deve apresentar uma lição teórica antes dos exercícios de cada módulo.✅ Implementado
RF05O sistema deve apresentar exercícios de múltipla escolha com correção automática.✅ Implementado
RF06O sistema deve apresentar exercícios de verdadeiro/falso com correção automática.✅ Implementado
RF07O sistema deve apresentar exercícios de ordenação de blocos de código (Parsons problems) com correção automática.✅ Implementado
RF08O sistema deve conceder XP por exercício correto, com valor diferenciado conforme o número de tentativas (RN02).✅ Implementado
RF09O sistema deve conceder medalhas por conquistas específicas do aluno.✅ Implementado
RF10O sistema deve exibir um ranking dos alunos da turma ordenado por XP (RN03).✅ Implementado
RF11O sistema deve fornecer um painel para o professor com relatórios de desempenho da turma.✅ Implementado
RF12O professor deve poder editar/adicionar conteúdo pedagógico pela própria interface.🔜 Próximos passos

⚙️ Requisitos Não Funcionais (RNF)

IDDescriçãoStatus
RNF01A aplicação deve ser responsiva (desktop, tablet e celular).✅ Implementado

RNF03A aplicação não pode depender de servidores externos nem fazer requisições a APIs externas.✅ Implementado
RNF04A aplicação deve funcionar sem instalação, direto no navegador.✅ Implementado

RNF06A aplicação deve ser compatível com os principais navegadores (Chrome, Firefox, Edge).✅ Implementado
